lolesterrr/DOZIIn progressAndroid

Dozi

A pharmacology study app for pharmacy students at Mbarara University of Science and Technology.

It works offline first and is built for 3 GB phones and expensive data bundles. So far it has notes with image annotation, flashcards scheduled with FSRS, image occlusion cards, and a quiz builder with six question types. A study day rolls over at 03:00, not midnight. The mascot will be a grey crowned crane in a lab coat.

lolesterrr/URC-INVENTORY-SYSTEMInternship

URC IT Inventory

An IT asset register for Uganda Railways Corporation.

It started as my internship prototype. I've since rebuilt it for a Windows Server inside the company network, with no cloud services. It has server-side sessions with argon2id password hashing, four roles enforced on the server, an append-only audit log protected by SQLite triggers, and nightly backups that are integrity-checked before they're kept. 50 automated tests cover it.

  • React 19
  • Express 5
  • TypeScript
  • SQLite
  • Drizzle
  • Vitest
  • Tailwind

lolesterrr/URC-HELPDESKInternship

URC Helpdesk

A Flutter and Django rebuild of a helpdesk.

It recreates the core of Frappe Helpdesk as a two-tier app: tickets with teams, priorities and types, conversations that keep customer replies apart from internal notes, assignment, feedback ratings and a small knowledge base. Sign-in uses JWT, and customers only ever see their own tickets.

  • Flutter
  • Dart
  • Django REST Framework
  • JWT

Monsieur Pierre

A desktop cat for macOS. You've probably met him already.

My fork of oneko-swift. I added a second, lazy cat: a fat tuxedo cat whose sprites I drew in Python. He naps, sits on the active window and rides along when you drag it, holds whatever you copy, tells you about new mail, and tells jokes in a speech bubble. The original chaser got personal space, eyes that follow the cursor, and a jump when you swing the mouse too hard.

lolesterrr/Travelling_SalesmanAlgorithms

Travelling Salesman

Two ways to find a short round trip.

Exact Held-Karp dynamic programming over an adjacency matrix, and a self-organising map that pulls a ring of nodes toward the cities until it becomes a route. Both are in Python, with written reports.

  • Python
  • NumPy
  • Matplotlib

lolesterrr/ve-inferenceAPI

ve-inference

Image embeddings over HTTP.

A small FastAPI service. Send an image to /embed and get back its 512-number CLIP embedding. It runs ViT-B/32 on the CPU in half precision to halve the model's memory, and ships as a Docker image.

  • Python
  • FastAPI
  • PyTorch
  • CLIP
  • Docker
